# Vulnerability Sentinel

A Paperclip plugin for deterministic vulnerability matching and report-only triage.

## Implementation status

Repository bootstrap only. The plugin is not implemented or installed yet.

The first version will use OSV fallback matching, KEV/EPSS enrichment, provenance records, and serialized finding-card creation. Report-only operation does not remediate, dismiss findings, or deploy changes.
